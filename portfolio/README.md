# Personal Portfolio — Rajput Sukhvendrasingh

A responsive, animated personal portfolio built with HTML5, CSS3 and Vanilla JavaScript.

## Run the project

Open `index.html` directly in a browser, or use VS Code Live Server.

## Files

- `index.html` — main portfolio
- `style.css` — portfolio styles and responsive design
- `script.js` — navigation, theme, reveal effects, typing and project modals
- `cv.html` / `cv.css` — printable resume page
- `assets/certificates/` — replace certificate placeholders
- `assets/project-screenshots/` — replace project mockup assets
- `assets/images/` — profile or project photographs

## Personalization

Add the real photograph under `assets/images/` when available. Certificate and project screenshot placeholders should be replaced without changing the provided project status or claims.

The CV is printable as PDF using the browser print dialog; no PDF library or backend is required.
